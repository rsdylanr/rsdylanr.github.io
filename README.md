# 🧰 Toolbox
12-tool static site. Pure HTML/CSS/JS, no build step, no deps, no backend.

## Tools
Password · Base64 · Hash · JSON · Color · UUID · Timestamp · Text Stats · Case · Lorem · URL · Regex

## Deploy
Paste the DSL into auto_deploy_gui.py → pick output folder → paste GitHub repo URL → Deploy.
On GitHub: Settings → Pages → Deploy from branch → main / (root) → Save.
Site lives at https://USERNAME.github.io/REPO/

## Local preview
`python -m http.server` in the output folder, then http://localhost:8000
